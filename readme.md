# Femora 🌸
### A Women's Health & Wellness Platform

Femora is a MERN Stack web application that provides reliable and easy-to-understand information about women's health and wellness.

## About the Project

The platform aims to reduce misinformation and improve access to health resources related to:

- Menstrual health
- Pregnancy and maternal care
- Mental health
- Nutrition and fitness
- Healthy lifestyle practices

## Main Features

- User Registration & Login
- Menstrual Health Information
- Menstrual Cycle Tracker
- Pregnancy & Maternal Care Guide
- Mental Health Resources
- Nutrition & Fitness Tips
- Health Articles & Blog
- FAQ
- Emergency Helpline Information
- User Feedback
- Admin Dashboard
- Nearby Hospitals & Clinics *(Optional)*

## Tech Stack

**Frontend:** React.js, Vite  
**Backend:** Node.js, Express.js  
**Database:** MongoDB, Mongoose  
**Version Control:** Git & GitHub

## Setup

Clone the repository:

```bash
git clone https://github.com/sarashawlin280-cyber/Femora
cd Femora
```

Install frontend dependencies:

```bash
cd client
npm install
```

Install backend dependencies:

```bash
cd ../server
npm install
```

Create `server/.env`:

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
```

## Run

Frontend:

```bash
cd client
npm run dev
```

Backend:

```bash
cd server
npm run dev
```
